# سایت فوتبالیست‌های انرژی اتمی

نسخه نمایشی اولیه با Next.js آماده شده است.

## اجرا
```bash
npm install
npm run dev
```

سپس آدرس محلی نمایش‌داده‌شده را باز کنید.

## انتشار روی Vercel
این پوشه را در GitHub قرار دهید و در Vercel گزینه Import Project را بزنید.

### نکته
این نسخه «ظاهر و ساختار اولیه» است. برای فعال شدن واقعی ورود کاربران، دیتابیس، آپلود رسید، ثبت نظرسنجی و ذخیره اخبار باید در مرحله بعد یک backend/database (مثلاً Supabase) متصل شود.
